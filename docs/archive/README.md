# Archived Work

This directory is the destination for code or documentation that has been
deliberately parked. Anything here is **not** built, tested, or referenced
by CI, and is kept for historical context only.

## How to archive something

1. Move the directory or file here with `git mv`.
2. Remove any references from build/test configs (`scripts/`, `package.json`,
   CI workflows).
3. Add a short note in this file or alongside the moved work explaining:
   - What it was
   - Why it was archived
   - Where the tracking issue or replacement lives
